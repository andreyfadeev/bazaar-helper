# Bazaar Helper

Веб-помощник по мета-сборкам The Bazaar (герой Pygmalien, сезон 19): подсказывает, какие предметы брать
у торговца под текущую сборку, и ведёт историю забегов.

**Программа никак не взаимодействует с игрой**: не читает экран, память, логи и файлы игры, не делает скриншотов,
не управляет мышью и клавиатурой и не работает как оверлей. Все предметы вы вводите сами.

Рекомендации — подсказка по данным гайда, а не гарантия победы.

## Как пользоваться
1. Укажите в шапке день, золото и (по желанию) цель сборки.
2. В каталоге выберите, куда добавлять: «Доска», «Торговец» (с ценой) или «Стеш», — и нажимайте на предметы.
   Поиск: начните печатать название, Enter добавит первый найденный.
   В режиме «Торговец» после выбора предмета курсор встаёт в поле цены: введите её и нажмите Enter.
3. «Торговец предлагает» покажет оценку 0–100 и вердикт: «Брать» (65+), «Зависит» (40–64), «Пропустить» (< 40)
   с причинами. «Купил» переносит предмет на доску и списывает золото.
   Последнее действие с забегом можно отменить: кнопка «отменить» в уведомлении или Ctrl+Z.
4. «Сборки и прогресс» показывает, насколько собран каждый архетип и чего не хватает.
5. После забега — вкладка «История»: сборка, число побед, заметки. Там же средние победы по сборкам.

## Данные
- Источник: [Mobalytics — Meta Builds](https://mobalytics.gg/the-bazaar/guides/meta-builds), обновлено 12.10.2026.
  Встроенные данные лежат в константе `DEFAULT_DATA` в `index.html`.
- Сборки вне меты (Double Whammy, Freeze, Riceballer, Money Furnace, Landscraper, Square, Luxury Kiuas,
  Yetarian Club) — из гайдов Kripparrian на [Mobalytics](https://mobalytics.gg/the-bazaar/builds), декабрь 2025 — июнь 2026.
  В интерфейсе они помечены «вне меты», у каждой указаны дата и ссылка на гайд.
- Экономические предметы (Loupe, Rewards Card, ATM, Cash Register) взяты из старых гайдов — проверяйте актуальность.
- Картинки предметов подгружаются с CDN Mobalytics и в репозитории не хранятся.
- Шрифты Philosopher и Alegreya Sans лежат в `fonts/` (лицензия SIL OFL 1.1, тексты лицензий рядом),
  поэтому страница не обращается к Google Fonts. Единственный внешний адрес — CDN картинок Mobalytics.
- Всё состояние хранится только в `localStorage` вашего браузера (ключ `bazaarHelper.v2`). Никаких аккаунтов,
  аналитики и отправки данных. Вкладка «Данные» — экспорт и импорт в JSON.

## Устройство
Один статичный `index.html` (HTML + CSS + JS) без сборщиков, фреймворков и бэкенда. Публикуется через GitHub Pages.

Проверка логики оценки: откройте `tests.html` (на сайте или через любой локальный сервер). Страница грузит
`index.html?nostore` в скрытый фрейм и прогоняет формулы из ТЗ; сохранённый забег не затрагивается.
Запускайте её после каждого обновления данных под новый сезон.

Неофициальный фан-проект, не связан с Tempo Storm и Mobalytics.
